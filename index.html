Formule
Ce code contient du texte et plusieurs formules : en validant, il sera converti automatiquement en paragraphes et en équations séparées.
Astuces : tapez / pour une fraction, ^ exposant, _ indice, « sqrt », « int », « sum », « alpha », « pi », « inf », « -> »… Tab ouvre la recherche de symboles, → passe à la case suivante, Entrée valide.
Écrivez la formule naturellement : les chiffres deviennent des indices, ^2+ une charge, -> une flèche, <=> un équilibre, (aq) (s) (g) les états.
