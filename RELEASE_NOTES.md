## Nouveautés

- **Dessins TikZ : le code s'écrit dans un panneau en bas de la fenêtre**, comme la console Python, et non plus sous le dessin dans la feuille.
  - La feuille ne montre que le dessin, à sa vraie place : il n'est plus poussé à la page suivante en laissant une demi-page vide.
  - Le panneau s'ouvre quand on sélectionne un dessin TikZ (ou avec « Modifier le code » à droite) et se cache quand on sélectionne autre chose ; le dessin suit la frappe.
  - Les erreurs du code s'affichent en bas du panneau. Le panneau se redimensionne à la souris, se réduit ou se ferme.
  - Un nouveau dessin TikZ met directement le curseur dans le code.
